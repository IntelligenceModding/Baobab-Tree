<p align="center">
  Baobab Tree helps you build large, ancient, and dry baobab landscapes in Minecraft.
</p>

<p align="center">
  It focuses on baobab-themed trees, the full wood family, roots, litter, fruit pods, and custom world generation for open warm terrain, while still fitting naturally into vanilla-style survival and building.
</p>

</p>

<p align="center">
  Install JEI alongside Baobab Tree if you want in-game descriptions for the non-obvious mechanics, otherwise the mod works normally without it.
</p>

</p>

<p align="center">
  Baobab Tree currently includes the following features:
</p>

<p align="center">
  &bull; Full baobab wood set, including signs, hanging signs, boats, and chest boats<br>
  &bull; Young, mature, ancient, and fallen baobab tree world generation<br>
  &bull; Hollow ancient trunks and smaller hollow fallen trunks<br>
  &bull; Tree roots with climbable behavior and harvesting interactions<br>
  &bull; Baobab litter with rummaging, pod finds, biome tinting, and custom particles<br>
  &bull; Plantable baobab fruit that grows beneath baobab leaves in multiple pod stages<br>
  &bull; Small, medium, and large baobab fruit pods that can be harvested, crafted, placed, or gathered after falling
</p>
